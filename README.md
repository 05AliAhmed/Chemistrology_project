# CHEMISTROLOGY

## About the Game

CHEMISTROLOGY is a 2D arcade puzzle game that combines fast-paced gameplay with educational chemistry content.

In this game, players control a rotating duck positioned within an atom's orbit. Their objective is to shoot electrons towards the correct orbital targets and construct real chemical elements.

Players must aim accurately, hit targets, and build combos to increase their score. Missing a target sends the electron into the **No-No Zone**, resulting in a score penalty. Floating asteroids and other obstacles provide additional challenges throughout the levels.

As players progress, new mechanics are introduced, including faster electrons, disappearing electrons, and rockets that reset the player's electron. After completing a level, players can unlock a real-world chemistry fact about the element they constructed.
